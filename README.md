## 🌟 Overview
A complete, mobile-first, animated traditional Marwadi royal wedding invitation website designed with a modern cinematic reel aesthetic.

- **Theme Palette:** Deep Royal Maroon (`#2a050f`, `#4a0a1a`), Antique Gold (`#dfb965`, `#c59b4c`), Warm Ivory & Parchment (`#fdfbf7`, `#fbf5ea`).
- **Opening Sequence:** Royal sliding palace gates with golden elephant crests, Sanskrit blessings, and "आमंत्रण पत्र खोलें" interactive button.
- **Hero & Animations:** ReactBits-inspired BlurText typography reveal, subtle golden stardust particle canvas, countdown live timers, scroll-triggered fade reveals.
- **Authentic Music:** Background traditional song *“Baisa Ro Roop”* with floating royal disk widget (play/pause, animated soundbars, user-initiated playback).
- **Bride & Groom Portraits:** Dedicated separate portrait cards with Rajputana golden arch borders and complete lineage details.
- **Ceremonies & Functions:** Complete event cards (Ghritpaan, Bandoli, Aashirwad & Preeti Bhoj, Mangal Pheras) with exact dates, times, and venue pins.
- **Exact Location:** Authoritative home Google Maps link (`https://maps.app.goo.gl/ednQQ7jofGRWWvdb6`) and Patel Chhatrawas venue directions.
- **Family Memories:** Cherished separate family portraits with graceful frames and warm Hindi captions.
- **Sister Spotlight:** High-quality photo & quote celebrating sister Ritika.
- **Emotional Tribute:** Brother Bhagirath Choudhary's heartfelt message to his sister Ritika.
- **Final Blessing Screen:** The very last screen displaying **॥ राम राम सा ॥** with slow golden glow fade-in.

## 🚀 How to Run & Preview

### Option 1: Direct File Preview (Instant & Works Offline)
No server or internet needed!
1. Double-click **`index.html`** in this folder.
2. It will open instantly in your default web browser (Chrome, Edge, Firefox, Brave, Safari).
3. All animations, music player, images, and countdown will work right away.

---

### Option 2: One-Click Localhost Server (`http://localhost:8000`)
1. Double-click **`start_server.bat`**.
2. It will automatically launch a lightweight PowerShell HTTP server and open `http://localhost:8000` directly in your browser.
3. Keep the small console window open while viewing. Press `Ctrl + C` or close the window when you are done.

---

### Option 3: Python Server (If you have Python installed)
Open a terminal in this directory and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
